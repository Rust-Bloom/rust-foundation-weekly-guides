# Learning resources

These are the main resources we use at Rust Bloom. They're all free. You don't need to work through them on your own: each weekly guide tells you exactly which part to do and when.

## 1. The Rust Book
Our main textbook. It explains Rust from the very beginning. We use the interactive version, which has short quizzes to check your understanding.

- Interactive version: <https://rust-book.cs.brown.edu>
- Standard version: <https://doc.rust-lang.org/book>

## 2. Rustlings
Small exercises where you fix broken code. They follow the Book chapter by chapter, so you practise what you've just read.

<https://github.com/rust-lang/rustlings>

## 3. Rust by Example
Short, runnable examples. Useful when a concept in the Book feels abstract and you want to see it in action.

<https://doc.rust-lang.org/rust-by-example>

## 4. Rust Playground
Write and run Rust in your browser, with nothing to install. Handy for quick tests, or if you can't install Rust yet.

<https://play.rust-lang.org>

## 5. Exercism Rust track
Extra practice later on, with feedback from volunteer mentors.

<https://exercism.org/tracks/rust>

## Tools

- Rust itself: <https://rustup.rs>
- VS Code: <https://code.visualstudio.com>, with the **rust-analyzer** extension
