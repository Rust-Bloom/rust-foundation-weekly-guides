# Rust Bloom: Weekly Guides

Rust Bloom is a community for women learning Rust, building with it, and contributing to open source.

This repository holds our weekly learning guides, our resources, and members' work.

## Weekly guides

Each week has one guide with clear steps. Go at your own pace, and start with Week 1.

| Week | Guide | What you'll do |
| --- | --- | --- |
| 1 | [Install Rust and write your first programs](weeks/week-01.md) | Install Rust, set up your editor, write Hello World and a guessing game |

A new guide is added each week.

## Resources

The books and tools we use are listed in [resources.md](resources.md).
